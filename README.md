# Tohid Developer

Portfolio + digital services storefront for Tohid Developer.

## Current stack
- HTML5
- CSS3
- Vanilla JavaScript
- GitHub REST API for public project cards
- JSON product catalog

## Features
- Responsive dark developer UI
- Services and digital products
- Order request form
- GitHub projects loaded dynamically
- UPI + Binance payment placeholders
- No payment credentials stored in the frontend

## Product catalog
Edit `products.json` to change product names, prices and descriptions.

## Payment
Payment details are intentionally not committed yet. Add them only when final UPI/Binance details are ready.

## Safety
Only sell/deploy software for legitimate and authorized use. Do not use the storefront to advertise spam, account abuse, ban evasion, credential theft, malware, or platform-protection bypasses.
